# Data Cleaning Report

Generated by `src/clean.py` from `data/processed/combined_hourly.csv`, writing `data/processed/cleaned_hourly.csv`. See that script's docstring for the full justification of each rule.

## Rules applied

1. Hours with <50% of minutes present were treated as unreliable and blanked before imputation.
2. Per-floor outliers: energy outside median +/- 3xIQR (wide 'extreme outlier' bound, chosen so real demand peaks survive).
3. Blanked/outlier hours imputed via linear interpolation (gaps <= 3h) then seasonal-naive fill (same floor, hour-of-day, day-of-week median).
4. Sensor columns (temperature/humidity/lux) got light interpolation only (gaps <= 6h); longer gaps and Floor 1 (no sensors at all) are left NaN for feature engineering to handle explicitly.
